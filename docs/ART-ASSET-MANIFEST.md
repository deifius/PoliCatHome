# Independent artwork: provenance and permissions

The software itself (including procedural WebGL and JavaScript scene source)
is BSD 3-Clause. Independent illustration files, photos, icons from outside
the project, and original spline-cat artwork are **not automatically** covered
by the software or documentation license.

No independent third-party illustration files are knowingly included in the
current packaged repository. Before publishing any new art, add one record per
asset with the following fields and obtain permission from its actual owner:

| Asset path | Creator / copyright holder | Provenance / source | Written permission or license | Attribution | Verified by and date |
| --- | --- | --- | --- | --- | --- |
| _(add verified assets here)_ | | | | | |

Only assign a license once the rightsholder confirms it. Original project-owned
art can be offered under CC BY 4.0 or another explicitly chosen license, but
**no choice is presumed by this manifest**. References to Thurber's style and
to the 1995 film *Hackers* are inspirations, not a license to copy art.
