WHAT YOUR BROWSER CAN CONTRIBUTE THIS DEVICE, NOT THE HOSTING SERVER

Catnap runs on your own device in a browser Web Worker, only after you enroll and press Start Catnap. Just visiting this page or watching the Gibson scene does not donate compute.

✓ AVAILABLE IN BROWSER

Best-effort local CPU time for the built-in SHA-256 chain task; choose a 5–75% pacing target, choose trusted approved Cats, pause or revoke consent.

✕ NOT AVAILABLE IN BROWSER

No general-purpose Catbox/Docker workloads, native/GPU acceleration, background compute after closing the tab, or guaranteed CPU, temperature, energy, and OS nice limits.

◎ TO ACTUALLY CONTRIBUTE

You need a secure HTTPS/localhost connection, your own PoliC and explicit consent. To receive work, opt in to at least one approved Cat creator. Keep the tab open and visible.

Your browser's CPU may consume power or generate heat during work. The slider is cooperative pacing, not a hard resource cap. No payment is promised. Want enforceable resource controls or native GPUs? You will need a separately installed native agent.

How to pause, revoke and remove everything you run. Browser Catnap needs no Docker installation. A Docker Catbox needs an explicit local shell command; this web page cannot remotely start it.

      
The ZIP is a source snapshot, not a Git clone with commit history. Run commands locally; do not paste operator tokens into this web page. Hosting a Commons and contributing compute are separate opt-in actions.

      
Quick local start (Python 3.10+)
unzip PoliCatHome-source.zip
cd PoliCatHome-source
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
export POLYC_ADMIN_TOKEN="$(python -c 'import secrets; print(secrets.token_urlsafe(36))')"
polyc serve --db runtime/browser.sqlite --host 127.0.0.1 --port 8765
Then open http://127.0.0.1:8765/. For public hosting, read the security guidance first: the development server should not be exposed directly to the Internet.
